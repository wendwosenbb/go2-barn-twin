# Barn visit checklist

Name every photo after the item: `FAN_TUNNEL_03.jpg`, `DOOR_END_01.jpg` (prefixes in `library/equipment_types.csv`).
Number items along +x, starting from the −x end wall.

## Before scanning
- [ ] Pick the origin: a spot inside the barn, clear of equipment, where mapping starts. Robot there, **facing down the length of the barn** (map x = barn x)
- [ ] Photo of the robot at the start spot, showing its heading and the nearest post (`ORIGIN_01.jpg`); tape-measure the spot to the nearest post and wall
- [ ] Note what is open or closed: end doors, tunnel doors, curtains, inlets
- [ ] Note feeder and drinker line heights (they move as the flock grows)
- [ ] Note which fans, heaters and lights are running

## Scan
- [ ] Start mapping at the origin spot; end back on it (closes the loop)
- [ ] Cover both end walls, the control room, the fan end, the cooling pads
- [ ] Walk outside past the fans and feed bins if possible

## Lines and spacing (tape-measure; the map checks it later)
- [ ] Spacing between neighbouring lines across the barn, wall to wall: wall → line → line → … → wall, ____ m each
- [ ] Order of lines across the barn (e.g. wall, drinker, feeder, drinker, …, wall)
- [ ] Feeder pan spacing along a line ____ m; pans per line ____
- [ ] Drinker nipple / cup spacing along a line ____ m; nipples per line ____
- [ ] Where each line starts and ends (distance from the end walls), and any gaps in a line
- [ ] Photo of one feeder pan and one drinker nipple close up, with a tape in the shot

## Migration fences
- [ ] How many fences ____; distance of each from the −x end wall ____ m
- [ ] Fence height ____ m; mesh or solid; how it passes under the feeder and drinker lines
- [ ] Do the fences stay put, or move between flocks?
- [ ] Photo of one fence, including how it attaches to the walls

## Cool cells (evaporative cooling pads)
- [ ] Which end and which side walls have cool cells
- [ ] Each cool cell: start and end distance from the end wall ____ m, height above floor ____ m, pad height ____ m
- [ ] Is there a tunnel door or curtain in front of the pad? Open or closed during the scan?
- [ ] Photo of each cool cell from inside and, if possible, outside

## Photos: nameplates (make, model, size)
- [ ] One tunnel fan, one sidewall fan, one circulation fan (each different model too)
- [ ] Heaters
- [ ] Feed hopper, feed bin
- [ ] Winches (and which lines each one lifts)

## Photos: control room
- [ ] Climate controller: every equipment / stage setup screen
- [ ] Electrical panel breaker labels (lists every motor and heater)
- [ ] Water meter, medicator, filters

## Small things the lidar will miss (photo + tape-measure from the nearest post)
- [ ] Temperature, humidity, static pressure, gas sensors
- [ ] Bird scales
- [ ] Farm cameras (and which way they look)
- [ ] Fogger lines (nozzle spacing)

## Floor and walkway
- [ ] Floor surface (concrete or earth), litter type and depth
- [ ] Drains
- [ ] Anything hanging low in the robot's path: pipes, cables, chains
